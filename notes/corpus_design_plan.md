# Corpus v3 — 50 hand-written manuals

Each document: 12,000–17,000 words, written as prose in its own language.
No Python templating. Distinct topic per document, except five deliberate
cross-language collisions (marked ‡) which are where cross-lingual retrieval
is exercised.

## The five topic collisions (‡)

| Broad topic | Documents |
|---|---|
| recruitment and selection | Bengali 01, Telugu 03 |
| travel and expenses | Hindi 03, Telugu 04 |
| separation / final settlement | Bengali 04, Telugu 07 |
| disciplinary process | Hindi 05, Kannada 01 |
| training | Hindi 07, Kannada 02 |

5 of 50 documents share a broad topic with another = 10%. Within each pair the
subject matter is split so no rule, figure, procedure or sentence appears in
both: e.g. Bengali 01 covers requisition, sourcing and interview panels while
Telugu 03 covers advertising, candidate assessment scoring and offer release.

## Content-disjointness rule

Every figure (days, months, rupees, percentages, committee sizes, deadlines)
is stated in exactly one document. A fact ledger is kept alongside the corpus
as each document is written, recording document, section and value, so the
query set can be built against it and so no later document restates an earlier
one's number.

## Structure that keeps 14,000 words distinct

Each manual carries its own: scope and definitions; eligibility; the procedure
step by step; roles and approval authority; timelines and service standards;
documentation requirements; exceptions and special cases; worked examples;
escalation and appeal; review and governance. Sections are written to the
document's own subject, never boilerplate shared between documents.
